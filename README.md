# -PersonaHub

PersonaHub — AI 驱动的 GitHub 用户画像分析工具。 输入任意 GitHub 用户 ID，通过分析其 timeline、contributions 和 stars， 自动生成用户技术偏好报告。支持 ReAct 智能体、流式输出、Nitro 后端。
